# TrilhaSaúde

Aplicativo web demonstrativo para acompanhamento de consultas, exames e etapas da jornada de cuidado.

## Arquivos
- `index.html`: página principal e carregamento dos arquivos.
- `style.css`: identidade visual, layout responsivo e tema escuro.
- `app.js`: navegação, cadastro/login demonstrativo, consultas, exames, jornada, notificações, perfil e mensagens simuladas.

## Como executar
1. Extraia a pasta `TrilhaSaude`.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador ou use a extensão **Live Server** no VS Code.
4. Crie uma conta de demonstração na tela inicial.

Não é necessário instalar dependências.

## Observações importantes
- Este é um protótipo acadêmico executado no próprio navegador.
- Os dados são guardados no `localStorage` do navegador e não são sincronizados entre dispositivos.
- O chat é uma simulação; não envia mensagens para uma equipe real.
- O cadastro/login é demonstrativo, não substitui autenticação segura em servidor.
- Não utilize dados reais, documentos, laudos ou informações médicas de pacientes.
- Para uso real, será necessário desenvolver back-end, banco de dados, autenticação segura, controle de acesso, criptografia, política de privacidade e adequação à LGPD.
- O aplicativo organiza informações e não substitui orientação, diagnóstico ou decisão de profissionais de saúde.
